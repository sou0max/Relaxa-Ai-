# Relaxa-Ai-
O **Relaxa Aí!** foi desenvolvido com o objetivo de proporcionar uma experiência acessível e agradável para quem busca momentos de pausa, foco e descompressão na rotina.   Seja para desacelerar durante um dia corrido de estudos/trabalho ou para monitorar hábitos de bem-estar, a plataforma combina uma interface simples com funcionalidades diretas.
