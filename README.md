# 🌿 Relaxa Ai!

> **Encontrando a calma na cidade.**

O **Relaxa Ai!** é um aplicativo de mapeamento e curadoria colaborativa focado na experiência emocional dos espaços urbanos. O objetivo é ajudar usuários a encontrarem refúgios calmos, seguros e inspiradores para trabalhar, estudar, relaxar ou socializar, evitando surpresas com barulho ou lotação.

---

## 🚀 Funcionalidades do MVP

* 📍 **Mapa Colaborativo:** Descubra locais calmos próximos a você com visualização interativa.
* 🎯 **Filtros Práticos:** Busque por nível de silêncio, presença de Wi-Fi, áreas verdes e espaços pet-friendly.
* ⭐ **Avaliação Emocional:** Sistema de avaliação (1 a 5 estrelas) focado na "tranquilidade" do local.
* 👥 **SocialHub:** Conecte-se com amigos para ver avaliações, recomendações e relatórios de visitas.
* ➕ **Cadastro de Locais:** Adicione novos refúgios na cidade com fotos, categorias e descrições.

---

## 🛠️ Tecnologias Recomendadas

* **Frontend:** Flutter / React Native
* **Backend:** Node.js / Firebase
* **Mapas & Geolocalização:** Mapbox API / Google Maps API
* **Banco de Dados:** PostgreSQL / Firestore

---

## 📱 Telas Principais

1. **Mapa Interativo:** Navegação e busca rápida de refúgios.
2. **Detalhes do Local:** Fotos, nota de "relax", tags e avaliações de usuários.
3. **Cadastro de Espaços:** Formulário para inclusão de novos locais com imagens e categorias.
4. **SocialHub:** Feed com atividades e locais visitados por amigos.
5. **Perfil do Usuário:** Gerenciamento de conta, histórico e preferências.

---

## 💡 Modelo de Negócio

O aplicativo opera em modelo **Freemium** + **B2B**:
* **B2C Grátis:** Acesso às funcionalidades essenciais de busca e avaliação.
* **B2C Premium:** Acesso a filtros avançados, navegação sem anúncios e uso offline.
* **B2B:** Destaque no mapa e métricas para estabelecimentos parceiros (cafés, espaços de bem-estar).
